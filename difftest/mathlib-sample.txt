# Declarations exported from a mathlib checkout for the nightly run, together
# with their transitive dependencies. They are chosen to reach kernel paths the
# standard library alone does not: deep instance chains, large universe
# expressions, well-founded recursion, quotients and classical choice.
#
# Every name here is a mathlib declaration, not a Lean core one. A core name
# such as `Classical.em` or `Quotient.mk` is present after `import Mathlib` and
# would export cleanly, but its closure is already covered by the `init` and
# `std` corpora, so it would add nothing.
#
# The list is checked, not assumed: `difftest/lean/CheckNames.lean` reports a
# verdict per name against the real environment, and the nightly job runs it
# before exporting. A name that is not a declaration would be skipped by
# lean4export or abort it, and either way the corpus would quietly not be what
# this file says it is. An earlier version of this file began with
# `Mathlib.Algebra.Group.Defs`, which is a module path rather than a
# declaration.
#
# Blank lines and lines starting with '#' are ignored.
